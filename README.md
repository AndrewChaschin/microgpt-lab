# microgpt-lab · Предсказание и обучение

**Русский** · [English](README.en.md)

В этой браузерной лаборатории небольшой трансформер учится предсказывать следующую букву слова. Выберите русское или английское слово, нажмите «Обучить на слове» и сравните прогнозы до и после шага обучения. Щёлкните по блоку схемы, чтобы увидеть формулу.

## Локальный запуск

Понадобятся npm 10 или новее и одна из поддерживаемых версий Node.js (`^20.19.0 || ^22.12.0 || >=24.0.0`).

```sh
npm ci
npm run dev
```

Откройте локальный адрес, который напечатает Vite. После установки зависимостей лаборатория работает автономно.

## Сборка
