# microgpt · Предсказание и обучение

Интерактивная лаборатория показывает, как небольшой трансформер предсказывает следующую букву русского слова и как обучение меняет его веса. Можно пройти по схеме вычислений, сравнить значения до и после обновления и проверить прогнозы на 20 отложенных словах. Модель обучается в фоновом потоке браузера на 100 учебных словах.

## Локальный запуск

Понадобятся Node.js 22.12 или новее из ветки 22.x и npm 10 или новее. Полный перечень поддерживаемых версий Node.js указан в `package.json`.

```sh
npm ci
npm run dev
```

Откройте локальный адрес, который напечатает Vite. После установки зависимостей лаборатория работает автономно.

## Сборка

```sh
npm run check
npm run build
npm run preview
```

Каталог `build/` содержит статический сайт. По умолчанию он собирается для корня домена. При размещении в подпапке укажите её путь при сборке. Следующая команда собирает сайт для репозитория GitHub Pages с именем `microgpt-lab`.

```sh
BASE_PATH=/microgpt-lab npm run build
```
